🌱 FarmTwin AI

AI-Powered Smart Farming & Crop Protection System

FarmTwin AI is an intelligent agriculture solution designed to help farmers improve productivity using Artificial Intelligence and Data Science. It enables early crop disease detection, efficient irrigation, and data-driven farming decisions.

---

🚀 Features

- 🌿 AI-based Crop Disease Detection
- 💧 Smart Irrigation Recommendations
- 📊 Data Visualization using Matplotlib
- 🤖 Machine Learning Prediction Model
- 📁 Dataset-driven insights

---

🛠️ Tech Stack

- Frontend: React (JSX)
- Backend: Python
- Libraries: Pandas, NumPy, Scikit-learn
- Visualization: Matplotlib
- Dataset: CSV

---

⚙️ Installation & Setup

1. Clone the repository

https://github.com/sabari1911/FarmTwin AI.git

2. Navigate to the project

cd FarmTwin-AI

3. Install dependencies

pip install -r requirements.txt

4. Run the project

python model.py

📊 How It Works

- Collects agricultural data from dataset
- Processes using Machine Learning algorithms
- Predicts crop diseases and irrigation needs
- Displays insights through visual graphs
